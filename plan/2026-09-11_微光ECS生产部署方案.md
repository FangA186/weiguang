## 目标

将当前微光部署到阿里云 ECS `i-bp1e515soalhovys9z98`（华东1杭州），第一阶段通过 `http://47.114.50.170` 访问。

## 方案

- 不安装宝塔。使用 Docker Compose 运行 FastAPI 和 PostgreSQL，复用服务器已有 Nginx反向代理 `127.0.0.1:8080`。
- 前端在 API 镜像构建阶段生成，运行时由 FastAPI 提供；用户图片和音频继续使用 OSS。
- 公网 IP 阶段使用 `APP_ENV=staging`、非 Secure Cookie，可信来源仅允许该 IP。正式域名和 HTTPS 启用后切换 production 与 Secure Cookie。
- 发布包从本地 `.env` 选取已存在的云服务参数，随机生成独立数据库密码；不包含本地数据库、node_modules、dist 或无关素材。
