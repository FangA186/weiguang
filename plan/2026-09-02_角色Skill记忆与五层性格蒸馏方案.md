## 1. 方案背景与目标

目前微光（Weiguang）已具备**百炼声音复刻（Voice Clone）**、**多模态对话**与**聊天截图文字提取**基础能力，但角色人设目前仅使用单字段纯文本 Prompt（`system_role`、`character_manifest`），缺乏对真实人物**语言口癖、喜怒哀乐逻辑、关系边界与专属共同记忆**的精细化建模。

参考业界 [perkfly/ex-skill](https://github.com/perkfly/ex-skill) 的蒸馏理念，本项目将把“**五层 Persona 性格架构 + 共同记忆库 Memories + 动态纠偏 Corrections**”深度集成到微光中，实现**“声音 + 语言风格 + 情绪逻辑 + 专属回忆”全链路闭环**。

---

## 2. 核心架构设计

### 2.1 数据与 Prompt 三层结构

1. **Part A: 五层 Persona 人设结构**：
   - **Layer 0（硬规则与红线）**：称呼禁忌、回避话题、必须遵守的行为底线。
   - **Layer 1（身份与背景）**：姓名/昵称、关系定义、相处时长、当前状态。
   - **Layer 2（表达风格与口癖）**：高频词、口头禅（如“好叭”“哼”）、句式长短、标点习惯（如波浪号～）、emoji 偏好。
   - **Layer 3（情感逻辑与情绪触发）**：什么情况撒娇、什么情况生气冷战、如何表达不满、如何被哄好。
   - **Layer 4（互动行为模式）**：日常相处节奏、压力下的表现、面对质疑时的回应方式。

2. **Part B: 共同记忆库 (Memories)**：
   - **关系时间线**：重要日期、里程碑、纪念日。
   - **共同习惯与仪式**：每日晚安、固定周末活动、共同爱好。
   - **专属黑话与梗**：专属昵称（pet names）、只有彼此懂的 inside jokes。
   - **生活偏好清单**：饮食喜好/忌口、旅行娱乐偏好。

3. **Part C: 动态纠偏修正层 (Corrections)**：
   - 用户在使用过程中随时指出“她平时不这么说话，她一般会说……”；
   - 系统自动解析为 Correction 规则，作为最高优先级指令前置注入 Prompt，实现“越聊越像”。

## 3. 技术实施规划

### 3.1 数据库持久化层
- 新增数据库迁移文件：`internal/auth/migrations/010_character_skills.sql`
- 创建 `character_skills` 表：
  - `id` (UUID PRIMARY KEY)
  - `user_id` (UUID NOT NULL REFERENCES app_users(id) ON DELETE CASCADE)
  - `name` (VARCHAR)
  - `relationship_info` (TEXT)
  - `personality_tags` (TEXT[])
  - `raw_input_text` (TEXT)
  - `persona` (JSONB)
  - `memories` (JSONB)
  - `corrections` (JSONB)
  - `is_active` (BOOLEAN DEFAULT TRUE)
  - `created_at`, `updated_at`

### 3.2 后端蒸馏与 Prompt 编译
- `backend/providers/skill_distiller.py`：
  - 实现两阶段蒸馏流程：
    1. `distill_persona(...)`：分析输入文本与标签，提取五层 Persona JSON。
    2. `distill_memories(...)`：分析关键事实与偏好，提取 Memories JSON。
- `backend/skill_store.py`：
  - 管理 `character_skills` 的 CRUD 与活跃状态切换。
  - 实现 `compile_system_instruction(...)`：将 Persona + Memories + Corrections 动态编译为极致拟真的 Markdown System Prompt。
- `backend/app.py` 路由：
  - `POST /api/skills/distill`：上传聊天文本/主观描述/性格标签，异步/同步蒸馏 Skill。
  - `GET /api/skills/active`：获取当前用户的活跃 Skill。
  - `PUT /api/skills/active`：手动微调 Persona / Memories。
  - `POST /api/skills/corrections`：新增纠偏规则。
  - `DELETE /api/skills/corrections/:id`：删除指定纠偏。
  - 接入现有 SSE 流式对话与语音生成：自动加载用户的活跃 Skill 编译指令。

### 3.3 前端交互界面
- 在客户端 `frontend/src/` 中新增 `components/CharacterSkillDialog.vue`：
  - **智能生成向导**：粘贴聊天记录或描述，勾选性格特征（恋爱性格、依恋类型、吵架模式），一键提取。
  - **记忆与人设看板**：可视化卡片查看与编辑五层性格、时间线、黑话与生活偏好。
  - **口癖纠偏管理**：快捷添加“语气/习惯修正”，即时生效。
- 聊天主界面集成快捷纠偏反馈入口。

---

## 4. 验证与验收标准

1. **蒸馏准确性**：上传样例聊天记录与性格标签，能准确解析出高频词、口头禅、情绪模式与时间线；
2. **Prompt 编译保真度**：在 SSE 文本与语音对话中，AI 输出严格体现该角色的口癖（如语气词、标点、emoji）与已知记忆；
3. **动态纠偏生效**：添加“请多发波浪号，不要用感叹号”等修正后，下一轮回复立即改变表达习惯；
4. **数据安全与规范**：所有 Skill 数据严格由 PostgreSQL 权威存储，遵守禁止 `localStorage` 规则，实时音频链路零阻塞。
