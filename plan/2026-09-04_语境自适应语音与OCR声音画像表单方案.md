## 官方依据与当前实现

本节“当前实现”描述调研时基线；实现后的差异见文末验收记录。

- [HTTP API](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api)：当前 qwen-audio-3.0-tts-flash 使用 SpeechSynthesizer HTTP/SSE，input.rate 为0.5–2，input.instruction 为自然语言指令，input.sample_rate 为采样率。
- [HTTP使用指南](https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide)：支持在 input.text 中加入情感、富语言标签。
- [实时指南](https://help.aliyun.com/zh/model-studio/realtime-tts-user-guide)：标签适用于 Qwen-Audio-TTS Plus/Flash；文档注明仅单向流式，不应将此能力直接套用到双向流式模式。控制类标签作用于后续文字，直到下一个标签或自动切句；富语言标签在当前位置插入拟声。
- 已核对前端 api/index.ts：浏览器会将rate/instruction放入访问微光后端的查询参数，F12可见；后端API Key不在前端。后台转发不等于前端输入参数不可见。
- 已核对 ChatView.buildMessages：本轮图片/视频作为多模态content parts发给LLM；历史消息目前只组装文本，不能声称旧图片/视频都已持续参与分析。
- 当前TTS按句调用，但整轮共用同一个rate/instruction；尚无逐句语境规划或显式标签注入。

## 标签范围

截至调研，官方列出23个控制类、7个富语言标签。没有发现官方承诺任意自定义方括号标签都有效；使用已公开集合，自由描述走instruction。

控制类：sad、amazed、deep and loud shouting、trembling、angry、excited、sarcastic、curious、like dracula、bored、tired、scornful、shouting、asmr、panicked、mischievously、empathetic、whispers、reluctantly、crying、serious、very slowly、very fast。

富语言类：gasp、sighing、clears throat、giggles、laughing、cough、snorts。线上默认启用常用温和标签；夸张风格供明确选择。后续官方更新再扩充，不声称当前表格是模型内部穷尽全集。

## 后端自动规划

1. 前端提交conversation_id、persona_id、本轮文字/附件引用、自动或手动选择；服务端校验归属，从数据库读取人设和有效声音配置。服务端提示词与动态声音计划不回传普通聊天页面；用户本身填写的设置仍可在浏览器看到。
2. 复用同一次多模态LLM调用：输出逐句结构化记录，每条含display_text、rate建议、emotion/style标签及可选句前/句后拟声。与现有纯文本流接口分开实现解析，避免破坏文字聊天。
3. 第一条完整且通过验证的记录立即进入有界TTS队列。不要先等待完整回答再增加一次逐句分析请求。首句解析超时或字段不合法时使用角色默认声音，不能随意丢弃正文。
4. 每个分句生成专用input.instruction和input.rate；在input.text前后注入白名单标签。正文在独立字段，原始模型控制文本不得提前通过text.delta外泄。不允许标签改变正文事实或插入任意语言内容。
5. 优先级为用户锁定项 > 本轮语境判断 > OCR角色基调 > 系统默认。自动速度建议限制0.85–1.15；显式手动可用官方0.5–2范围。手动锁定语速时禁用very fast/very slowly等冲突标签；情绪锁定时移除冲突情绪标签。采样率不随情绪改变。
6. 标签只影响尚未合成的分句；已经播放的声音不可追溯修改。图像/视频是语境材料，不代表其中人物的真实心理状态或声音特征。
7. 每轮关联使用的视觉输入/可复用视觉摘要，后续需要历史图片时从本会话的受权附件读取并续签；不能把其它会话素材混入。额外视觉输入或分析调用需进入成本遥测。

## 展示与重播

页面显示：`别着急，我们慢慢说。`

后端TTS示例（方案示例，非当前已上线请求）：

```json
{
  "model": "qwen-audio-3.0-tts-flash",
  "input": {
    "voice": "owned-voice-id",
    "text": "[empathetic]别着急，我们慢慢说。",
    "rate": 0.9,
    "instruction": "平静共情，语调柔和，停顿自然。",
    "sample_rate": 24000
  }
}
```

正文、分句声音计划、配置版本和音频标识分别保存。重播优先复用首次完整音频；缓存失效使用已保存计划恢复，不重新分析出另一套情绪。若要求逐字节相同必须保留原音频，重新调用TTS不能承诺相同。音频存储设置保留期限与容量边界，中断回合不得标记为完整音频。

## OCR 完成后的表单

审核页增加“声音画像（可选）”，可展开查看和修改；与角色工坊共用字段、数据库持久化。展示文字推断来源，不强制填完。

| 字段 | 自动填充原则 | 用户控件 |
|---|---|---|
| 声音呈现（男性/女性/中性） | 仅素材明确自述时给建议，否则未指定；是目标音色设定，不是识别人身份 | 可选选择 |
| 声音年龄感 | 不从用词、头像猜真实年龄，默认未指定 | 可选年龄感 |
| 音调 | OCR没有声学证据，默认自然 | 自然/偏高/偏低；作为描述，数值pitch另行验证 |
| 语速 | 从句长与表达节奏给朗读建议，不当作真实语速测量 | 跟随语境/固定倍速 |
| 情绪基调 | 按文字互动归纳温柔、活泼等基调，具体每句可自动调整 | 自动/固定基调 |
| 声音特点 | 清脆、沙哑、磁性等不能从截图可靠测量 | 多选目标声音特点 |
| 使用场景 | 本产品默认日常陪伴，可改朗读/讲解等 | 场景选择 |
| 拟声表达 | 默认少量，可关闭 | 自动少量/关闭/手动白名单 |
| 补充描述 | OCR已有依据才建议 | 可编辑文本 |
| 输出采样率 | 默认24kHz，不从素材自动判断“高清” | 24/48kHz |

复刻音色优先保持原音色特征，不自动强制改变性别/年龄感；这些描述不等于声音设计或重新训练音色。选择声音特点时提示效果依赖所选音色。

涉及 backend/app.py、providers/qwen_llm.py、新建有界声音计划解析模块、Persona/OCR表单和共享类型。新表/列迁移按 internal/auth/migrations/ 后续序号创建；同步HANDOFF和PROGRESS。

验收需覆盖：图片/视频语境传入；逐句正文与标签分离；碎片跨边界解析；手动锁定优先；无效标签/超时回退；跨会话隔离；中断同时取消LLM/队列/TTS；低额度不超量；拟声也按实际音频时长结算；重播一致性；24/48k音频可解码。
