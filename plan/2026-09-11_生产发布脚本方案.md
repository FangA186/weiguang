# [已完成] 生产发布脚本方案

> **状态**：已完成 (Completed)
> **创建时间**：2026-09-11
> **完成时间**：2026-09-11

## 目标

提供一个本地入口脚本，完成用户端、管理端、后端运行镜像的构建与发布包生成；服务器应用脚本保留现有 PostgreSQL 数据卷和 `.env.production`，发布失败时恢复上一版镜像、管理端静态文件和 Nginx 配置。

## 约束

- 服务器无法稳定访问 Docker Hub，发布包必须携带 `linux/amd64` API 镜像。
- 不把 `.env`、数据库密码、API Key、原始卡密或本地数据库装入发布包。
- 未配置 `DEPLOY_TARGET` 时只生成单个发布包；配置后才通过项目专用 SSH 密钥自动上传执行。
- 发布前只执行不写共享业务数据的检查。

## 验收标准

- 单命令生成一个可上传的 `.tar.gz` 发布包和 SHA-256。
- 包内包含 API 镜像、管理端静态文件、Compose/Nginx 配置与服务器应用脚本。
- 服务器脚本发布前备份数据库，且仅重建 API 服务，不重建 PostgreSQL。
- Shell 语法、目标回归、类型检查、生产构建、镜像架构和发布包清单全部通过。

- 新增包内服务器脚本 `deploy/apply-release.sh`：保留服务器 `.env.production` 和 PostgreSQL 数据卷，发布前使用容器内 `pg_dump` 备份数据库，仅重建 API 容器；管理端静态文件和 Nginx 配置同步更新，失败恢复上一版镜像与文件。
