## 方案概要

将 GitHub 开源项目 [perkfly/ex-skill](https://github.com/perkfly/ex-skill) 的核心能力（五层 Persona 人格蒸馏 + Memories 共同记忆库 + 动态纠偏）接入微光陪伴系统，实现：

1. **一键蒸馏**：从微信聊天记录自动提取五层人格特征与共同记忆
2. **角色工坊**：多角色卡片管理、创建、切换
3. **越聊越像**：对话中实时纠偏，持久化学习
4. **独立记忆**：不受上下文窗口限制的事实知识库
5. **版本管理**：人设快照与一键回滚

## 技术架构要点

- 新增 `personas`、`persona_versions`、`persona_corrections` 三张 PostgreSQL 表（`internal/auth/migrations/010_personas.sql`）
- 新增 `backend/prompts/` 提示词模板（`persona_analyzer.md`, `memories_analyzer.md`, `correction_analyzer.md`）
- 新增 `backend/persona_store.py`、`backend/persona_distiller.py`、`backend/prompt_compiler.py`、`backend/correction_handler.py` 后端核心模块
- REST API 完整支持角色 CRUD、激活、蒸馏、版本快照回滚、动态纠偏
- 前端新增 `PersonaWorkshopDialog.vue`、`DistillWizardDialog.vue`、`CorrectionDialog.vue`、Pinia `usePersonaStore`
- 对话时将编译好的 `compiled_prompt` 替换现有的单一 `character_manifest` 注入
- 蒸馏为离线异步任务，绝不阻塞实时语音链路
