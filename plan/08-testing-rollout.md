# 测试、验收、监控与上线方案

## 1. 测试分层

### 单元测试

- JSON Schema 校验；
- ZIP 安全解压；
- 文件大小和文件数限制；
- 视频和未知附件过滤；
- 图片 MIME 校验、EXIF 清理和去重；
- 消息规范化和幂等导入；
- Chunk 切分；
- 重要度计算；
- 事实冲突和有效期处理；
- 上下文 token 预算和裁剪顺序；
- 全文/向量结果融合；
- MMR 去重；
- collection、asset 和 fact 权限检查。

### 集成测试

- PostgreSQL 迁移和外键级联删除；
- Redis 任务队列恢复；
- Worker 重试与幂等性；
- pgvector HNSW 检索；
- 全文 GIN 检索；
- WebSocket 会话绑定记忆库；
- TTS 中断和音频队列取消；
- 图片鉴权读取。

### 端到端测试

- 上传两份记忆库；
- 切换记忆库并询问同一个问题；
- 文本与语音询问同一历史事实；
- 图片 OCR、描述和直接视觉读取；
- 删除记忆库后验证所有数据不可访问。

## 2. 导入测试矩阵

| 场景 | 预期 |
|---|---|
| 空 JSON | 明确拒绝 |
| 只有文字 | 正常 ready |
| 文字和图片 | 正常导入并异步分析图片 |
| 包含视频 | 视频删除并计入报告 |
| 损坏图片 | 文字保留，图片警告 |
| 重复图片 | 通过 SHA-256 去重 |
| 路径穿越 ZIP | 拒绝 |
| 压缩炸弹 | 拒绝 |
| 重复提交同一导入 | 不重复创建消息 |
| Worker 中途退出 | 任务超时后可恢复 |

## 3. RAG 评测集

建立脱敏测试集，每条包含：

```text
query
expected_collection
expected_message_ids
expected_facts
should_use_memory
```

覆盖：

- 精确关键词；
- 同义表达；
- 人名；
- 相对时间；
- 长期偏好；
- 事实冲突；
- 图片文字；
- 普通寒暄；
- 无答案问题。

指标：Recall@5、MRR、无关记忆注入率、引用准确率和平均检索耗时。

## 4. 浏览器验收流程

1. 上传“工作聊天”数据。
2. 上传“家庭聊天”数据。
3. 查看两份清洗报告。
4. 确认视频被删除、图片可预览。
5. 选择“工作聊天”，询问工作相关历史。
6. 查看回答引用来源。
7. 切换“家庭聊天”，询问同一问题。
8. 确认没有引用工作数据。
9. 分别用文本和语音询问相同历史事实。
10. 确认核心事实和最终正文一致。
11. 语音播放中执行打断。
12. 确认旧音频不再播放。
13. 删除一份记忆库。
14. 确认消息、图片、facts 和 chunks 不可再访问。

## 5. 安全测试

- 用户 A 访问用户 B 的 collection；
- 用户 A 访问用户 B 的 asset；
- 伪造 collection ID 和 asset ID；
- ZIP 路径穿越和符号链接；
- 文件扩展名伪装；
- 图片脚本/异常解码；
- 删除后使用旧 URL；
- Redis 查询缓存跨用户污染；
- 日志泄露聊天正文。

## 6. 监控指标

### 导入

- 导入成功率；
- 平均/P95 导入耗时；
- 清理消息数量；
- 删除视频数量；
- 图片分析失败率；
- Embedding 失败率；
- Worker 队列积压和重试次数。

### RAG

- 查询 Embedding 耗时；
- FTS 和向量检索耗时；
- RAG 总耗时与 P95；
- Redis 缓存命中率；
- 无结果率；
- 低相关结果被过滤比例；
- 用户查看引用比例。

### 对话

- 文本首 token 延迟；
- 语音首句延迟；
- 上下文超限次数；
- TTS 错误和中断次数；
- WebSocket 重连率；
- 记忆库切换失败率；
- 页面文本/TTS 不一致错误。

## 7. 灰度顺序

### 灰度一：内部账号

- JSON/ZIP；
- 视频清理；
- 图片保存；
- 记忆库管理；
- PostgreSQL 全文检索。

### 灰度二：少量用户

- pgvector；
- 长期事实和摘要；
- 文本/语音记忆；
- 引用来源展示。

### 灰度三：多模态实验

- 图片 OCR；
- 图片视觉描述；
- 多模态 API adapter 与媒体格式转换；
- 按需原图输入。

## 8. 回滚方案

- 全局和用户级 `memory_enabled` 开关；
- `memory_collection_id` 为空时回退无记忆模式；
- RAG 故障时回退当前会话短期历史；
- pgvector 不可用时回退全文检索；
- 图片分析故障时回退 OCR 或纯文本；
- 新索引版本未完成时继续使用旧版本；
- 多模态 provider 故障时回退 OCR/描述 + 文本模型；
- 数据迁移只新增表和字段，回滚应用版本不删除数据。

## 9. 最终验收目标

| 指标 | 目标 |
|---|---:|
| 视频误入数据库或长期存储 | 0 |
| 用户越权访问 | 0 |
| RAG 平均延迟 | ≤400ms |
| 文本上下文超限率 | ≤1% |
| 语音上下文超限率 | ≤1% |
| 无关记忆注入率 | ≤5% |
| 文本/语音核心事实一致率 | ≥95% |
| TTS 与页面最终文本一致率 | 100% |
| 删除记忆后的可访问残留 | 0 |

## 10. 阶段出口条件

每个阶段只有在以下条件满足后才能进入下一阶段：

- 该阶段迁移、单元测试和集成测试通过；
- 浏览器主业务路径通过；
- 权限和删除路径通过；
- 监控指标已接入；
- 降级路径已验证；
- 文档与接口类型同步更新。
