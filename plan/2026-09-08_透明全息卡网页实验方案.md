# [已完成] 透明全息卡网页实验方案

> **状态**：已完成 (Completed)
> **创建时间**：2026-09-08
> **完成时间**：2026-09-09

## 目标

将“微光”全息收藏卡处理为卡牌外部透明的 PNG，并制作一个独立网页验证鼠标倾斜、流光高光和移动端布局。

## 范围

- 实验文件独立放入 `marketing_assets/2026-09-08/holo-card-experiment/`。
- 使用原生 HTML、CSS 和少量 JavaScript，不接入主 Vue 路由、不新增依赖。
- 验证 PNG Alpha 通道、页面资源加载、桌面交互和窄屏布局。

## 验收条件

- 卡牌外部像素存在透明 Alpha。
- 网页可加载卡牌，鼠标移动能改变倾斜与流光位置。
- 页面在桌面和约 390px 宽度下无横向溢出。

## 验收总结

- 透明卡图为 1024×1536 RGBA PNG，`sips` 检查确认包含 Alpha 通道。
- HTML 和内联 JavaScript 静态检查通过；本地 HTTP 页面可正常加载图片。
- 浏览器实测卡牌完整显示，指针移动后倾斜与流光 CSS 参数发生变化。
- 390×844 视口下页面宽度为 390px、无横向溢出；卡牌位于可视范围内。
- 未接入 Vue、后端或 Blender，实验仅包含一个 HTML 和一个 PNG。
