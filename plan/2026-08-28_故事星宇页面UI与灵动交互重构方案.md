## 1. 现状痛点与重构目标

### 1.1 现状核心问题（基于用户截图与代码审查）
1. **卡片大面积重叠遮挡**：原 3D 球体上所有正面节点均直接展开宽度达 240px 的大矩形卡片（`.node-pill`），在球体正面挤成一团杂乱的灰色重叠块，不仅遮挡左上角标题文案，也破坏了浩瀚星空的深邃美感。
2. **缺乏灵动与情感共鸣（Whimsy 缺失）**：原本的星空较为静态，缺乏流星划过、点赞星芒粒子爆炸、星轨涟漪互动与精致的星语微动效。
3. **视觉层级不够精炼**：星子节点与卡片缺乏清晰的“默认星子轻量标签 -> 悬浮星语浮笺 -> 聚焦聚光灯详情”的三级渐进式展开层次。

## 2. 重构架构设计（UI Designer + Whimsy Injector）

### 2.1 视觉层级与渐进式呈现（UI Designer）
- **第一层（默认态 - 星子光芒与微型名帖）**：
  - 球面上每个故事表现为**呼吸光晕的灵动星子（Starlight Beacon with 4-point sparkle）**；
  - 附带精致微型的名帖胶囊（例如 `✦ 晓涵 · 深圳` 或 `✦ 阿泽 · 广州 📷`），字号精简优雅（高度 ~24px），在 3D 旋转中通透不拥挤。
- **第二层（悬浮态 - 星语浮笺 Whisper Card）**：
  - 鼠标悬浮或靠近某颗星子时，星子放大并向外绽放柔和星晕，平滑展开毛玻璃微光浮笺（展示金句摘录与点赞数），伴随微小星芒闪烁。
- **第三层（选中聚焦态 - 星芒聚光灯 Spotlight）**：
  - 点击星子后，星体自动缓动对齐视线，并在右下侧/中心弹出毛玻璃高质感详情卡片，支持键盘左右键快速切歌般切换故事、全屏看图与点赞互动。

### 2.2 灵动趣味与情感微动效（Whimsy Injector）
1. **星际流星系统（Shooting Stars）**：Canvas 背景定期（随机 4~8 秒）划过一道优美的金白/冰蓝色流星，带有渐隐拖尾。
2. **点赞星芒粒子爆裂（Heart & Stardust Explosion）**：点击「❤️ 温暖了 X 人」时，触发 14 枚向上轻柔飘散、旋转闪烁的彩色星尘与爱心粒子。
3. **星海触控涟漪（Cosmic Ripples）**：点击星空空白处激起一道柔和金白光环，照亮周围星座连线。
4. **双击流星雨彩蛋（Easter Egg）**：双击星空空白区域触发流星雨坠落微动效与温馨微语提示。
5. **寄语投递星升动画**：投递新寄语成功后，新生成的星子在球面上高亮破晓诞生。
