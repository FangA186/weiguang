## 已确定的默认决策

- 第一版导入格式为标准 JSON 和 ZIP。
- 每份上传数据建立一个独立记忆库。
- 每个会话只选择一个记忆库，不在单个会话中静默混用多份记忆。
- 视频、音频和未知附件不保存；图片保留并生成缩略图、OCR 与视觉描述。
- PostgreSQL 保存结构化数据，Redis 负责异步任务和缓存。
- RAG 使用 PostgreSQL 全文检索（GIN）与 pgvector 向量检索（HNSW）。
- 文本和语音共用 `MemoryRetriever`，但采用不同上下文预算。
- 当前语音链路采用浏览器 `SpeechRecognition → qwen3.5-flash → Qwen-Audio-3.0-TTS-Flash`；暂不接入 Qwen、MiMo 或其他独立 ASR，TTS 只朗读已经生成并展示的文本。
- 文本、图片和视频由 `qwen3.5-flash` 理解；音频附件按需路由到 Qwen Omni 或 MiMo；用户上传和 provider adapter 尚需在新 API 链路中实现，模型能力全部通过云端 API 提供。
- 长期记忆导入第一版仍只保留图片并生成缩略图、OCR 与视觉描述；视频、音频和未知附件暂不进入长期记忆库。
